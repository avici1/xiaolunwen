# 小论文：门诊就诊与气象、空气污染物关系分析

本仓库存放小论文相关的 R 分析代码，用于研究门诊（脑出血、脑梗死）就诊人次与气象因素、空气污染物之间的关系。

仓库只包含代码，不包含原始门诊、住院或气象监测数据。

## 目录结构

- `1、数据处理/`：合并气象与空气污染数据、门诊数据处理、按日计数
- `2、描述性分析/`：就诊人次与气象、污染物的描述性分析
- `3、单变量模型调参/`：各气象因子与污染物的单变量模型调参
  - `放弃程序/`：未采用的调参脚本
- `4、双变量模型调参/`：双变量模型调参与作图
- `5、结果输出/`：单变量结果作图、汇总与整体模型

## 运行说明

脚本中的数据路径指向本机原始数据目录（例如 `F:/文章/小论文/`）。如需复现，请将路径改为自己的数据位置，并准备相应的 Excel / CSV 文件。

建议使用 R 与常用包：`dplyr`、`readxl`、`writexl`、`ggplot2`、`lubridate` 等。
